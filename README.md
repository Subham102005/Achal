# Achal
ACHAL (अचल, "unmoving") is an open-source, low-cost, AI-enabled system that watches the ground above shallow underground coal workings and warns people before it gives way. It is Team ACHAL's (NIT Jamshedpur) entry to Hack for a Social Cause, VBYLD 2027, category 7: AI, GIS &amp; Emerging Technologies.
